# 🎓 Learning docs

Short, visual pages for learning how this app works, without needing to be a software engineer.

**Every page follows the same pattern:**

| Section | What it gives you |
|---|---|
| 🖼️ The picture | One diagram of the whole topic |
| 🎯 The 20% that matters | The few ideas that explain 80% of what you'll see |
| 🧭 What you'd touch | Which files/settings you'd actually look at or change |
| ⚠️ Common traps | Mistakes that cost time |
| 📖 Go deeper | Links to official docs for full detail |
